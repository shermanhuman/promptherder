# promptherder

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Write your AI coding instructions once, distribute them to every agent you use.

```
.promptherder/agent/     (you edit here)
        │
        │  promptherder
        │
        ├──→ .agents/                         (Gemini CLI / Antigravity)
        ├──→ .github/                         (VS Code Copilot)
        ├──→ CLAUDE.md                        (Claude Code)
        ├──→ AGENTS.md                        (OpenAI Codex)
        ├──→ .cursor/rules/promptherder.md    (Cursor)
        ├──→ .windsurf/rules/promptherder.md  (Windsurf)
        └──→ .clinerules/promptherder.md      (Cline)
```

No more copy-pasting rules between `.agents/` and `.github/`. Edit in one place, run `promptherder`, done.

## Install

```bash
go install github.com/shermanhuman/promptherder/cmd/promptherder@latest
```

## Quick Start

```bash
# See what herds are available
promptherder list

# Pull Compound V (an AI coding methodology) and sync
promptherder pull compound-v
promptherder
```

Or if you just want to manage your own rules:

```bash
# Create your source directory
mkdir -p .promptherder/agent/rules

# Add a rule
cat > .promptherder/agent/rules/project.md << 'EOF'
# Project Rules

- All API routes require authentication.
- Use structured logging with slog.
- Prefer table-driven tests.
EOF

# Sync to all agents
promptherder
```

## Commands

| Command | What it does |
|---|---|
| `promptherder` | Sync to all enabled targets |
| `promptherder list` | Show available herd aliases |
| `promptherder pull <name>` | Pull a herd by alias |
| `promptherder pull <url>` | Pull a herd by URL |
| `promptherder agent list` | Show available/enabled targets |
| `promptherder agent add <name>` | Enable a target |
| `promptherder agent remove <name>` | Disable a target |
| `promptherder <target>` | Sync a single target |
| `promptherder --dry-run` | Show what would be written |

## Agent Management

By default, promptherder syncs to **copilot** and **antigravity**. Enable additional targets:

```bash
# See what's available
promptherder agent list

# Enable Claude Code and Cursor
promptherder agent add claude cursor

# Remove one you don't use
promptherder agent remove copilot

# Sync to all enabled targets
promptherder
```

Agent preferences are stored in `.promptherder/settings.json`:

```json
{
  "agents": ["antigravity", "claude", "cursor"]
}
```

All 7 targets: `copilot`, `antigravity`, `claude`, `codex`, `cursor`, `windsurf`, `cline`.
You can always sync a single target directly: `promptherder claude`.

## Herds

A **herd** is a shareable package of AI coding instructions — rules, skills, and workflows bundled together. [Compound V](https://github.com/shermanhuman/compound-v) is a herd. You can make your own.

Pull any herd from GitHub — by name or URL:

```bash
promptherder pull compound-v
promptherder pull oh
promptherder
```

The herd's rules, skills, and workflows get merged into your `.promptherder/agent/` source and synced to all targets on the next run.

## Aliases

promptherder ships with built-in aliases so you can pull herds by short name:

```
$ promptherder list

Available herds:

  compound-v     Agent methodology — planning, execution, review
  grugg          Token reduction prompt — ~75% fewer output tokens
  oh             Elixir/Go environment skills — starting template, customize for your stack

Config: ~/.config/promptherder/aliases.json
Pull:   promptherder pull <name>
```

The first time you run `list` or pull by name, promptherder creates `~/.config/promptherder/aliases.json` with the defaults. Edit it to add your own:

```json
{
  "my-stack": {
    "urls": [
      "https://github.com/shermanhuman/compound-v",
      "https://github.com/shermanhuman/oh"
    ],
    "description": "My full development stack"
  }
}
```

Full URLs still work: `promptherder pull https://github.com/someone/their-herd`

## Source Format

Rules live in `.promptherder/agent/rules/*.md`:

```markdown
# Hard Rules

- Do not generate plaintext secrets.
- All changes go through Git.
```

Path-scoped rules use frontmatter:

```markdown
---
applyTo: "**/*.sh"
---

# Shell Script Safety

Use `set -Eeuo pipefail`.
```

## Manifest

promptherder tracks written files in `.promptherder/manifest.json` for idempotent cleanup — if a source file is removed, its synced copies get cleaned up too. Commit this file.

## .gitignore

You'll probably want to ignore the generated target files and conversation state:

```gitignore
# Generated agent instructions (regenerated by promptherder)
.agents/
.github/copilot-instructions.md
.github/prompts/
.github/instructions/
CLAUDE.md
AGENTS.md
.cursor/rules/promptherder.md
.windsurf/rules/promptherder.md
.clinerules/promptherder.md

# Conversation artifacts (ephemeral)
.promptherder/convos/
```

Keep `.promptherder/agent/`, `.promptherder/hard-rules.md`, and `.promptherder/future-tasks.md` tracked — they're your project knowledge.

## Compound V

promptherder ships with **[Compound V](https://github.com/shermanhuman/compound-v)**, an AI coding methodology forked from [obra/superpowers](https://github.com/obra/superpowers). Five slash commands (`/plan`, `/execute`, `/review`, `/idea`, `/rule`), TDD discipline, 10-check parallel code reviews, YOLO mode for full autonomy. See the [Compound V README](https://github.com/shermanhuman/compound-v) for the full walkthrough with examples.
